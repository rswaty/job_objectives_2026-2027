# Start here

1. Copy this folder into your Obsidian vault, or open it as a new vault.
2. Install and enable the **Tasks** and **Dataview** community plugins.
3. Open and pin `00 - Objectives Dashboard`.

## Using the system

- Check off tasks where they are listed in the objective notes.
- Add tags directly to a task or note, such as `#FSC`, `#R-package`, `#publication`, or `#Northwoods`.
- Connect related notes with Obsidian links, such as `[[FSC dashboard]]` or `[[Kori Blankenship]]`.
- Add new tasks with `- [ ] Task description`.
- The dashboard automatically lists all open tasks, the 20 most recently completed tasks, and tags used in objective notes.

There are no evidence files, accomplishment templates, or weekly-review templates in this version.
