# Weekly team notes

Each Tuesday at 8:00am Eastern Standard Time (9:00am during daylight time), a GitHub Action drafts `YYYY-MM-DD.md` here and emails it to rswaty@tnc.org. Mail needs the `SMTP_USERNAME` and `SMTP_PASSWORD` repository secrets (Microsoft 365: `smtp.office365.com`, port 587). `MAIL_TO` defaults to rswaty@tnc.org.

**Date window:** tasks completed since the previous Tuesday, using the task checkbox date (`✅ YYYY-MM-DD`) only.

**Content:** prefer nested `Accomplishment:` lines — high-level outcomes, no dates. Never invent outcomes (email ≠ lead secured). If no accomplishment line exists, stay faithful to the completed task.

Paste the note into your team email (subject line is at the top). Keep completed work pushed to GitHub before Tuesday.
