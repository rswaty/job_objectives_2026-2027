# Weekly team notes

Each Tuesday ~8:00, a Cursor Automation drafts `YYYY-MM-DD.md` here.

**Date window:** tasks completed since the previous Tuesday, using the task checkbox date (`✅ YYYY-MM-DD`) only.

**Content:** prefer nested `Accomplishment:` lines — high-level outcomes, no dates on those lines. If an accomplishment is missing, paraphrase the completed task once at outcome level; do not invent detail.

Paste the note into your team email (subject line is at the top). Keep completed work pushed to GitHub before Tuesday.
